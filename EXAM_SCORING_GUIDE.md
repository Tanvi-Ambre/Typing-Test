# GCC TBC English Exam - Scoring Guide

## 📊 Exam Structure (Total: 100 Marks)

```
┌─────────────────────────────────────────────────────────────┐
│                    EXAM BREAKDOWN                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Section 1: OBJECTIVE (MCQs)                                │
│  ├─ 25 Questions × 1 mark each = 25 marks                   │
│  └─ Passing: 10 marks (40%)                                 │
│                                                              │
│  Section 2: SPEED PASSAGE (Typing Test)                     │
│  ├─ Total marks = 40 marks                                  │
│  ├─ Duration: 7 minutes                                     │
│  ├─ Target: 30 WPM, Max 14 errors                          │
│  └─ Passing: 16 marks (40%)                                 │
│                                                              │
│  Section 3: WRITING TASKS                                   │
│  ├─ Email Writing = 5 marks                                 │
│  ├─ Letter Writing = 15 marks                               │
│  ├─ Statement Writing = 15 marks                            │
│  ├─ Total = 35 marks                                        │
│  └─ Passing: 14 marks (40%)                                 │
│                                                              │
│  GRAND TOTAL = 100 marks                                    │
│  OVERALL PASSING = 40 marks (40%)                           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

---

## ✅ Passing Criteria (ALL Must Be Met)

### Rule 1: Section-wise Minimum (40% in EACH section)
```
✓ Objective:      ≥ 10/25 marks (40%)
✓ Speed Passage:  ≥ 16/40 marks (40%)
✓ Writing Tasks:  ≥ 14/35 marks (40%)
```

### Rule 2: Overall Minimum
```
✓ Total Score:    ≥ 40/100 marks (40%)
```

### ⚠️ CRITICAL: You must pass BOTH rules to pass the exam!

## 🔍 Quick Reference

### To Pass the Exam:
1. ✓ Score at least 10/25 in Objective
2. ✓ Score at least 16/40 in Speed Passage
3. ✓ Score at least 14/35 in Writing Tasks
4. ✓ Score at least 40/100 overall

### Common Mistakes:
- ❌ Scoring high overall but failing one section
- ❌ Passing all sections but total below 40%
- ❌ Ignoring section-wise requirements

### Pro Tips:
- ✓ Focus on weak sections first
- ✓ Aim for 50%+ in each section for safety margin
- ✓ Practice all sections equally
- ✓ Don't neglect any single section
