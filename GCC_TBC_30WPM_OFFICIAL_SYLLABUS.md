## ⚠️ CRITICAL PASSING CRITERIA

Must achieve ALL of the following:
1. **Section A (MCQ):** ≥10/25 marks (40%)
2. **Section B (Practical):** ≥14/35 marks (40%)
3. **Section C (Speed):** ≥16/40 marks (40%)
4. **Overall Total:** ≥40/100 marks (40%)

**FAIL if any single section is below 40%, even if overall is above 40%**

## 📝 KEY DIFFERENCES: 30 WPM vs 40 WPM

### 30 WPM (Our Exam):
- **Email:** Simple "E-Mail Etiquettes" (5 marks)
  - No CC/BCC mentioned
  - No multiple attachments mentioned
  - Basic email format

- **Letter:** MS-Word based (15 marks)
  - Simpler format
  - No Mail Merge mentioned

- **Statement:** MS-Excel based (15 marks)
  - Basic spreadsheet

### 40 WPM (Advanced):
- **Email:** Detailed with CC/BCC (5 marks)
  - CC and BCC fields
  - 2 file attachments
  - More complex

- **Letter:** Advanced with Mail Merge (15 marks)
  - Mail Merge for 2 recipients
  - Complex formatting

- **Statement:** Advanced Excel (15 marks)
  - Functions and formulas
