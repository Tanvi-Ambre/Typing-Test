# MCQ Modes Comparison

## Quick Reference Guide

### 📚 Practice Mode vs 📝 Test Mode

| Feature | Practice Mode | Test Mode |
|---------|--------------|-----------|
| **Purpose** | Learning & Understanding | Exam Simulation |
| **Immediate Feedback** | ✅ Yes - Shows correct/incorrect instantly | ❌ No - Results shown at end |
| **Correct Answer Display** | ✅ Shown immediately if wrong | ❌ Shown only after submission |
| **Score Visibility** | ✅ Real-time score updates | ❌ Hidden until submission |
| **Answer Changes** | ❌ Locked after selection | ✅ Can change before submit |
| **Visual Feedback** | ✅ Green/Red highlighting | ❌ No highlighting during test |
| **Best For** | First-time learners, concept review | Final preparation, self-assessment |

## Visual Flow

### Practice Mode Flow:
```
Select Question Set → Choose Practice Mode → Start
    ↓
Question 1 → Select Answer → ✓/✗ Immediate Feedback
    ↓
Next Question → Select Answer → ✓/✗ Immediate Feedback
    ↓
Continue... → Submit → Final Results → Review All Answers
```

### Test Mode Flow:
```
Select Question Set → Choose Test Mode → Start
    ↓
Question 1 → Select Answer (no feedback)
    ↓
Question 2 → Select Answer (can change previous)
    ↓
Continue... → Submit All Answers
    ↓
Final Results (Pass/Fail) → Review All Answers with Correct/Incorrect
```

## When to Use Each Mode

### Use Practice Mode When:
- 📖 Learning new material for the first time
- 🔍 Want to understand why answers are correct/incorrect
- 💡 Need immediate reinforcement of concepts
- 📝 Taking notes on difficult questions
- 🎯 Focusing on understanding over speed

### Use Test Mode When:
- ⏱️ Preparing for the actual exam
- 🎯 Testing your knowledge without hints
- 💪 Building exam confidence
- 📊 Getting realistic score assessment
- 🏆 Ready to simulate real exam conditions

## Scoring & Pass Requirements

Both modes use the same scoring criteria:
- **Total Questions**: 25
- **Pass Marks**: 10 correct answers (40%)
- **Scoring**: 1 mark per correct answer
- **Pass/Fail**: Displayed after submission

### Score Interpretation:
- **0-9 correct (0-36%)**: ❌ FAILED - More practice needed
- **10-15 correct (40-60%)**: ✅ PASSED - Basic understanding
- **16-20 correct (64-80%)**: ✅ PASSED - Good understanding
- **21-25 correct (84-100%)**: ✅ PASSED - Excellent understanding

## Recommended Learning Path

### Week 1-2: Practice Mode
1. Complete all available question sets in Practice Mode
2. Take notes on questions you get wrong
3. Review correct answers and understand why they're correct
4. Repeat until you consistently understand the material

### Week 3: Mixed Practice
1. Alternate between Practice and Test modes
2. Use Practice Mode for weak areas
3. Use Test Mode to build confidence
4. Track your Test Mode scores

### Week 4: Test Mode Focus
1. Complete full tests in Test Mode only
2. Simulate exam conditions (time yourself)
3. Aim for consistent 40%+ scores
4. Review any remaining weak areas

## Tips for Maximum Learning

### Practice Mode Tips:
1. **Read Carefully**: Don't rush - understand each question
2. **Learn from Mistakes**: When you get it wrong, read the correct answer carefully
3. **Take Notes**: Write down questions you find difficult
4. **No Guessing**: Think through each answer before selecting
5. **Review Patterns**: Notice common question types and topics

### Test Mode Tips:
1. **Time Management**: Don't spend too long on one question
2. **First Pass**: Answer all questions you know first
3. **Second Pass**: Return to difficult questions
4. **Review Before Submit**: Check all answers before final submission
5. **Stay Calm**: Treat it like the real exam - stay focused

## Common Mistakes to Avoid

❌ **Don't**: Jump straight to Test Mode without practice
✅ **Do**: Master material in Practice Mode first

❌ **Don't**: Rush through Practice Mode just to finish
✅ **Do**: Take time to understand each correct answer

❌ **Don't**: Get discouraged by low initial scores
✅ **Do**: Track improvement over time

❌ **Don't**: Only practice questions you got right
✅ **Do**: Focus extra time on questions you got wrong

❌ **Don't**: Memorize answers without understanding
✅ **Do**: Understand the concepts behind each answer
