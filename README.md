# 30 WPM Typing Test - GCC TBC English Exam Practice

A professional typing test application designed for practicing the GCC TBC (Government Commercial Certificate - Typewriting Basic Course) English exam at 30 words per minute.

## Features

- **Two Modes:**
  - Real-time Feedback: See errors as you type
  - Exam Mode: No highlighting until submission
  
- **Smart Error Detection:**
  - Word-based error counting
  - Only complete words are marked as errors
  - Current word being typed shows in yellow

- **Exam Specifications:**
  - 7-minute test duration
  - 30 WPM target speed
  - Maximum 14 errors allowed
  - ~210 words per passage
  - 2-3 paragraphs with proper indentation

- **Dynamic Content:**
  - 6 different topics (Technology, Education, Health, Environment, Communication, Business)
  - 30 sentences per topic
  - Random passage generation for variety
  - Thousands of possible combinations

- **Detailed Feedback:**
  - Real-time WPM calculation
  - Accuracy percentage
  - Error count tracking
  - Pass/Fail results
  - Error highlighting for review

## How to Use

1. Open the application in your browser
2. Toggle "Real-time Feedback" on/off based on preference
3. Click "Start Test" to begin
4. Type the passage exactly as shown (including 5-space indentation)
5. Press Tab key for paragraph indentation
6. Click "Submit Test" or wait for timer to end
7. Review your results and errors
8. Click "Start New Test" for another practice

## Technical Details

- Pure HTML, CSS, and JavaScript
- No external dependencies
- Responsive design
- Times New Roman font (14pt) - standard typing test format
- Word-based error calculation
- Tab key inserts 5 spaces for indentation

## Exam Standards

Based on GCC TBC English typing exam requirements:
- Speed: 30 WPM
- Duration: 7 minutes
- Error Limit: 14 errors maximum
- Format: Indented paragraphs with proper spacing
