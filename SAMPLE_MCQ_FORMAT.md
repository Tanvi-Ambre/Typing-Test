# Sample MCQ PDF Format

## Format Guidelines

The PDF should contain questions in the following format:

```
Question 1: What is the capital of France?
A) London
B) Paris
C) Berlin
D) Madrid
Answer: B

Question 2: Which planet is known as the Red Planet?
A) Venus
B) Mars
C) Jupiter
D) Saturn
Answer: B

Question 3: Who wrote "Romeo and Juliet"?
A) Charles Dickens
B) William Shakespeare
C) Jane Austen
D) Mark Twain
Answer: B
```

## Important Rules:

1. **Question Format:**
   - Start with "Question" followed by number and colon
   - Example: `Question 1:` or `Question 10:`

2. **Options Format:**
   - Use capital letters A, B, C, D followed by closing parenthesis
   - Example: `A)`, `B)`, `C)`, `D)`
   - Each option on a new line or separated clearly

3. **Answer Format:**
   - Start with "Answer:" followed by the correct option letter
   - Example: `Answer: B` or `Answer: A`

4. **Spacing:**
   - Leave blank lines between questions for clarity
   - Options can be on same line or separate lines

## Alternative Formats Supported:

### Format 1 (Compact):
```
Question 1: What is 2+2? A) 3 B) 4 C) 5 D) 6 Answer: B
```

### Format 2 (Detailed):
```
Question 1: What is the largest ocean on Earth?

A) Atlantic Ocean
B) Indian Ocean  
C) Arctic Ocean
D) Pacific Ocean

Answer: D
```

### Format 3 (With Categories):
```
[Geography]
Question 1: What is the capital of Japan?
A) Seoul
B) Tokyo
C) Beijing
D) Bangkok
Answer: B
```

## Tips for Creating Your PDF:

1. Use a consistent format throughout the document
2. Ensure question numbers are sequential
3. Double-check that all answers are marked correctly
4. Use clear, unambiguous language
5. Avoid special characters that might cause parsing issues
6. Test with a small sample first

## Common Issues and Solutions:

### Issue 1: Questions not detected
**Solution:** Ensure "Question" keyword is present with number

### Issue 2: Options not parsed correctly
**Solution:** Use standard format A), B), C), D)

### Issue 3: Answer not found
**Solution:** Use "Answer:" keyword followed by letter

### Issue 4: Duplicate questions
**Solution:** Ensure unique question numbers

## Testing Your PDF:

1. Upload a small sample (5-10 questions) first
2. Check if all questions are extracted correctly
3. Verify options are displayed properly
4. Confirm correct answers are marked accurately
5. If issues occur, adjust format and try again

**Note:** The application uses pattern matching to extract questions. Following the format guidelines ensures accurate extraction.
